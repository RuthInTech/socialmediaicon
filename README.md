# 🌐 Social Media Icon Project

This project showcases a clean and elegant **social media icon section** built using **HTML** and **CSS**.  
It features a soft gradient background, centered circular icons, and smooth hover animations — perfect for portfolio websites or landing pages.

---




> A responsive and minimal design to display social media links beautifully.

---

## 💻 Technologies Used

- **HTML5** – for structure  
- **CSS3** – for layout and hover effects  
- **Font Awesome** – for social media icons
